# Test character: Science 10. Skill 12 = Science.
#
# Expected: FLAGS 0 -> 32 (MG_F_KNOWS_TERMINAL) as soon as the screen has been seen;
#           karma 0 -> -2 at the first login (once); Q_INFO 0 -> 3 and FLAGS 96 -> 524384
