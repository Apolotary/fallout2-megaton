# him, GVAR_MG_SHOP_ALARM goes 0 -> 1 and her mercenary adds his own warning
# (-> 2). The second time she attacks and the alarm goes to 3, which turns the
# mercenary on the player too; the town as a whole stays peaceful.
#   python3 mod/megaton/tests/merchants/run_all.py theft
# Steal (skill 10) opens her inventory; dragging a coin out of the right-hand
# list and confirming the amount is one attempt. Being caught closes the screen.
# Session 1 tries eight times and then checks the warning with `expect` (if she
# never caught him, they fail: run it again). Session 2 cannot be checked that
# way: nobody knows which attempt is caught, and once it is, the mercenary's
# assault rifle soon kills the test character and the game returns to the main
# menu (all GVARs read 0 there, time=302400). So it prints the alarm at once
# and the state a second later after every attempt; the proof is a log line
# `gvar 657 = 3` with `gvar 645 = 0` (town not hostile), then `state ... combat=1`.
# The rig first gives the thief fifteen levels so that he outlives the first burst.
